# Security

eBeacon is a pre-1.0 personal project provided as-is. There are no maintenance,
response-time, support, disclosure, or security-fix commitments.

If you find something you think is a security issue, please **do not open a
public GitHub issue.** Email the maintainer at <chase.wright@ethereum.org>
instead. Reports are reviewed on a best-effort basis. There is no bug bounty.

By reporting an issue you accept that triage, fixes, and disclosure timing are
entirely at the maintainer's discretion, and that running eBeacon is at your
own risk.
