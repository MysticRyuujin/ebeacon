# Security

eBeacon is a pre-1.0 personal project. There are no maintenance, response, or disclosure commitments — formal or otherwise.

If you find something you think is a security issue, please **do not open a public GitHub issue.** Instead, open a private [GitHub Security Advisory](https://github.com/mysticryuujin/ebeacon/security/advisories/new). The maintainer may or may not respond, on no particular timeline. There is no bug bounty.

By reporting an issue you accept that triage, fixes, and disclosure timing are entirely at the maintainer's discretion, and that running eBeacon is at your own risk.
